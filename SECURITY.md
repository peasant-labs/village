# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository: open the **Security** tab, choose
**Advisories**, then **Report a vulnerability**.

Include the affected component and version or commit, impact, reproduction steps,
and any suggested mitigation. Remove real credentials, private transcript data,
and personal information from the report where possible.

Maintainers will acknowledge the report through the private advisory, investigate
it, and coordinate remediation and disclosure there. Response and remediation
times depend on severity and project capacity; this document does not promise a
fixed service level.

Only versions identified in published releases should be treated as supported.
Development branches may change without notice.
